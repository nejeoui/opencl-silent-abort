# Submitted reports

One file per machine, named `<chip>-<gpu cores>-macos<version>-<verdict>.txt`,
for example `m2-10c-macos26.3.1-reproduced.txt`.

Add a row to the results table in the top-level `README.md` in the same pull
request. Reports where the behaviour does **not** reproduce are wanted just as
much — they bound the problem.
